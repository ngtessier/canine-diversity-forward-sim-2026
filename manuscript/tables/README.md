# Main-text and supplementary tables — machine-readable form

These files reproduce, as CSV and XLSX, the tables that appear as formatted tables in the
manuscript. They were extracted from the manuscript, not recomputed; the manuscript remains
authoritative. Each file's first row is a note carrying the table's caption and source.

## Contents

| File | Manuscript item |
|---|---|
| `Table1_founder_and_gen20_diversity_metrics.csv` | Table 1 — founder (generation 0) and generation-20 diversity metrics by strategy in each breed |
| `Table2_allele_loss_final_five_generations.csv` | Table 2 — allele loss over generations 15–20, mean total alleles across all 33 loci |
| `Table3_allele_frequency_band_composition.csv` | Table 3 — allele frequency band composition, generation 0 vs generation 20 |
| `Table4_onyx_harriette_comparison.csv` | Table 4 — two highly inbred Standard Poodles with matching internal relatedness and opposite outlier index |
| `TableS7a_locus_positions_canFam4.csv` | Supplementary Table S7(a) — genome positions of the 33 panel loci on canFam4 |
| `TableS7b_inter_locus_distances.csv` | Supplementary Table S7(b) — distances between loci sharing an autosome |
| `TableS8_breedwide_VGL_statistics.csv` | Supplementary Table S8 — breed-wide statistics, UC Davis Veterinary Genetics Laboratory |
| `SimStudyI_MainAndSupplementary_Tables.xlsx` | All seven of the above, one per sheet |

## Notes on individual tables

**Table S7(a).** Positions determined by UCSC In-Silico PCR of published primer pairs
(Pedersen et al. 2012; Wictum et al. 2013) against canFam4 (UU_Cfam_GSD_1.0). Every amplicon
fell within its published size range. LEI004 is marked with a dagger: its published reverse
primer mismatches the canFam4 reference at one base, 4 bp from the 3′ end, and the position
was obtained with the corrected primer.

**Table S8.** A dated snapshot. The VGL breed statistics pages are recomputed as new samples
are tested, so these values are those retrieved on **20 August 2026** and will not match the
live pages at a later date. The access date is the citable element.

## Formatting

Minus signs and en-dashes from the manuscript are rendered as plain hyphens so the numeric
columns parse cleanly. Bold and italic markup is stripped. Blank spacer rows used for visual
grouping in the manuscript are omitted; breed grouping labels are retained as their own rows
in Tables 1 and 2, matching the manuscript layout.
